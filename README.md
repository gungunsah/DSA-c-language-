
Data Structures and Algorithms in C

A collection of Data Structures and Algorithms (DSA) programs implemented in the C programming language, written as part of my BCA (Bachelor of Computer Applications) Semester 2
coursework.

The goal of this repository is to build a strong foundation in problem solving, memory management, and core computer science concepts by implementing each data structure and 
algorithm from scratch, without relying on external libraries.

About the Project

This repository contains clean, well-structured C programs that demonstrate how fundamental data structures work internally. Each program is self-contained and can be compiled 
and run independently.

Highlights
Implemented entirely in C using pointers, structures, and dynamic memory allocation
Each concept is placed in its own file for easy reading and reference
Menu-driven programs for hands-on practice with operations
Code is commented to explain the logic step by step
